**AutoPlay** is an open-source mod for **Beat Saber** that generates hyper-realistic **BeatLeader replays (`.bsor`)** for any selected beatmap with a single click, and automatically launches the in-game replay viewer for you to watch.

## ⚖️ Disclaimer

- This mod is strictly intended for **beatmap demonstrations, replay viewing, algorithm learning, and research**.
- In all `.bsor` replays generated by this mod, the player is marked as "Auto Play".
- Do not use this tool for any activity that undermines the fairness of leaderboards or multiplayer rankings. Please respect the community guidelines of BeatLeader and Beat Saber.

## 🚀 Installation

1. Go to the [Releases](../../releases) page of this repository and locate the corresponding version of `auto_play.dll`—though, as it happens, we only have one version anyway :>
2. Copy `auto_play.dll` into the `Plugins` folder inside your Beat Saber installation directory:
   ```text
   YourBeatSaberPath/Plugins/auto_play.dll
   ```
   If you don't know where it is, right-click Beat Saber in Steam and select "Browse local files".
3. Launch the game for the mod to take effect.

## 🎮 How to Use

1. Launch Beat Saber and enter **Solo** mode.
2. Select your desired song and difficulty. You can also select Modifiers and Left-Handed mode. Player height is locked to 150 cm and cannot be modified.
3. You will see a **Pepe the Frog button** between the song list and leaderboard. Click it to generate the corresponding `.bsor` replay.
4. The mod will then automatically use the BeatLeader replay viewer to play the generated replay.
5. Enjoy the show!

### 📝 Structure

```
AutoPlay/
├── auto_replay.csproj        # Project file
├── AutoReplayGenerator.cs    # Replay data generation core
├── AutoReplayManager.cs      # Automation dispatch hub: fetches map & modifiers, drives generation and playback
├── AutoReplayMath.cs         # Math & kinematics utility library
├── LeaderboardPatches.cs     # Button / UI patches
├── NoteEventBuilder.cs       # Note cut event builder
├── NoteSwingPlanner.cs       # Saber swing planning algorithm (near perfect)
├── PepeButtonController.cs   # Pepe the Frog button controller
├── Plugin.cs                 # BSIPA initialization & Harmony patch management
├── PoseCalculator.cs         # Obstacle dodging controller (crouching and leaning)
├── ReplayFileSaver.cs        # Saves replay locally
└── manifest.json             # BSIPA mod metadata and dependency declarations
```
